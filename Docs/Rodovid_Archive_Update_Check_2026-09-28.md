## Середовище та ізоляція

Windows, Node.js 24.18.0, npm 11.16.0, залежності з `package-lock.json`
через `npm ci`. Робочий проєкт: `E:/PETprojects/Rodovid`.
Усі зміни даних виконувалися в `E:/RodovidZubenko/tmp/rod027-20260928/`:

- `initial/` — початкова копія 231 файла проєкту з маніфестом SHA-256;
- `work/` — окрема робоча копія з власними залежностями;
- `checkpoint/` — резервна копія 234 файлів після додавання тестових матеріалів;

Команди функцій резервування та відновлення взято безпосередньо з блоків
PowerShell інструкції; замінено лише шляхи на тестові. `node_modules`,
`dist`, `generated`, звіти й Git-історія не копіювалися. Перед встановленням
залежностей перевірено повний список, розміри та SHA-256 відновлених файлів.
Початкові спроби запису були зупинені sandbox; після наданого дозволу
операції виконано на тих самих окремих копіях.

Вхід — чинний експорт 17.09.2026, його журнал і доповнення. Лише в `work/`
додано явно синтетичні: Markdown-спогад для I1, PNG як медіа джерела,
джерело з доказовою прив’язкою, альтернативне ім’я та файл архівного
оригіналу. Заголовки й тексти позначені «ТЕСТ ROD-027», без історичних
тверджень. PNG — технічний однопіксельний приклад, не скан для оцінки якості.

## Повторні експорти та діагностика

Запущено на робочому репозиторії:

```text
npm test -- scripts/gedcom/convert.test.ts scripts/reimport.test.ts scripts/convert-data.test.ts scripts/memory-files.test.ts scripts/static-data-plugin.test.ts
```

**5 файлів, 30 тестів — успішно.** Зокрема: перенумерація XREF зі збереженням
повного предметного JSON, перестановка вкладених подій і їхніх доказів,
збереження ID у реальному повторному експорті, зупинка без явних відповідностей,
неприв’язані доповнення, безпечні Markdown-шляхи, заміна/вилучення матеріалів
та відмова збірки за некоректних файлів.

Журнали команд, звіти негативних сценаріїв, результати з хешами та знімки
`baseline-memory.png`, `updated-memory.png`, `restored-memory.png` залишені
у тестовій папці. Тимчасовий оркестратор перевірки —
`E:/PETprojects/Rodovid/tmp/rod027-check.mjs`; він не є командою оновлення
для власника й не входить до Git або сайту. Порядок ручного повторення
викладено в розділах 2–8 інструкції.

## Незмінність входів і межі висновку

Після перевірки всі **5 файлів реального `Data/`** збігаються з початковим
маніфестом. SHA-256 GEDCOM:
`a6428245adf900e2ec6bd84946d24945078e6d94d8bdfd96ce3b865c8232e506`;
RootsMagic: `2e66a9184acfd5c634448c02a58fefbe19a6a40d979b45914cc3dab42ec6722e`.
Архів `Magic/`, книги й дослідницькі матеріали не змінювалися.

ROD-026 лишається незавершеним. Прогін підтверджує технічне оновлення й
відновлення поточного набору та синтетичних матеріалів; він не означає
приймання реальних фото/сканів, резервування всього зовнішнього архіву
на другий носій або перевірку відкриття бази у RootsMagic. Виявлену
відсутність вхідної прив’язки `photoIds`/`portraitId` записано в ROD-026.

`npm ci` повідомив про одну наявну high-вразливість залежностей;
автоматичне оновлення lockfile не виконувалося. Повний аудит залежностей,
фізичний телефон і релізні перевірки цим документаційним тікетом не закриваються.
