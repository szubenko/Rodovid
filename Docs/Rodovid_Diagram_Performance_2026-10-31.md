# Плавність діаграм — 31.10.2026

Під час перетягування кожен `mousemove` раніше оновлював спільний стан
React. Це повторно обробляло сторінку й картки; кругова карта також
перезаписувала координати, прозорість і шляхи всіх вузлів та зв’язків.

`useMapCamera` тепер об’єднує події через `requestAnimationFrame` і змінює
тільки трансформацію камери, відсоток масштабу та розмір стрілок.
Стан React зберігається після завершення жесту, а також перед наступним
натисканням або клавіатурною дією, щоб кнопки й історія отримали актуальну
камеру. Початок жесту завершує активну анімацію зміни центру.
`useMapTransition` не перемальовує незмінну геометрію після руху камери.

## Контрольний замір

Локальна production-збірка, Chromium, viewport 1440×1000, CPU throttling 4×,
вміщена діаграма I1; для «Усі родичі» відкрито весь набір.
Однакові 120 подій руху з мінімальним інтервалом 8 мс.
Це навантажувальна перевірка, а не прогноз FPS на пристрої власника.

| Діаграма | React commits під час руху, до → після | Час JavaScript, мс, до → після | 95-й перцентиль інтервалу кадру, мс, до → після |
| --- | --- | --- | --- |
| Родинне коло | 120 → 0 | 9368 → 246 | 100,1 → 16,8 |
| Вертикальний новий дизайн | 120 → 0 | 14246 → 308 | 249,9 → 100,1 |
| Усі родичі | 120 → 0 | 22013 → 346 | 266,6 → 66,8 |

Після відпускання миші — один commit. У круговій карті кількість зайвих
змін вмісту SVG зменшилася з 32760 до 0. Велике дерево з портретами все
ще потребує часу на малювання SVG; фіксовані 60 FPS не гарантуються.
Експерименти з `will-change` і переміщенням усього SVG не дали стабільного
покращення й не включені до реалізації.

## Перевірки

- 19 модульних перевірок геометрії камери, переходів та історії.
- Браузерні сценарії для всіх шести діаграм: рух до відпускання миші без
  React commits, історія й наступний жест без стрибка, wheel перед кнопкою
  та клавіатурним переходом, переривання анімації, native touch/pinch.
- Наявні сценарії розмірів viewport, повноекранного режиму, колеса,
  підказок і горизонтальної навігації.
- Разом успішні 33 цільові браузерні сценарії в сукупності запусків;
  native touch на desktop пропущено, мобільний сценарій виконано.
- Lint, повна перевірка типів, стандартна збірка та збірка атласу.

Дані й матеріали архіву не змінені. Статуси та критерії ROD-011/012
залишаються незмінними.
