## Запуск і наступні оновлення

Подвійний клік по `start-local.bat` запускає локальний сайт і відкриває браузер.
Адреса — `http://127.0.0.1:5173`. Вікно слід залишати відкритим, зупинка —
`Ctrl+C`. Для перевірок без відкриття браузера: `start-local.bat --no-open`.

Дані готуються при кожному запуску. Після заміни GEDCOM потрібно додати
перевірене зіставлення до журналу, переглянути зауваження, виконати
`npm run data:validate` і перезапустити сайт. Генерований JSON вручну не редагується.
Для готової статичної копії — `npm run build`, потім `npm run preview`.
