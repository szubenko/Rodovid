# Родовід — окрема версія «Сімейний атлас»

Створено 11.10.2026 на запит власника: окрема версія сайту на React + TypeScript + SVG/D3 з оновленим дизайном.

Світла зелена палітра, бічний покажчик усіх людей, пошук за основними й альтернативними іменами, радіальна карта та особисті кімнати. На телефоні покажчик відкривається над вмістом. Дані, оцінки тверджень, докази та історія переходів походять із чинної моделі родоводу.

У новій версії карта відразу вміщується у доступну ширину; збільшення відкриває дрібні підписи. Для основної версії збережено її попередній початковий масштаб.

Поруч із «Родинне коло» є «Горизонтальний родовід» та «Вертикальний родовід».
У горизонтальній схемі предки праворуч, нащадки ліворуч; у вертикальній — предки
зверху, нащадки знизу, подружжя в одному рядку. Картки містять повні
імена й наявні роки, мають спільні керування, вибір доказів і PNG-експорт.
Початковий показ цих двох схем зосереджений на читабельних картках біля центру;
«Вмістити карту» показує всю поточну схему. Пошук, «До мене» й повернення з кімнат
зберігають вид карти, «Назад» відновлює попередню камеру.
Прямі адреси — `/horizontal/I1` і `/vertical/I1`.

Уточнення 13.10.2026: вертикальна схема також показує братів/сестер і партнерів
у видимих родинах. «+» біля картки додає її родичів, «−» згортає додану гілку.
«Показати всіх родичів» вміщує повний пов'язаний граф у вікно (74 людини та
118 зв'язків у поточному наборі). Кожна людина має одну картку; всі вихідні
зв'язки доступні для доказів, стан гілок відновлюється через «Назад».
«Початкові гілки» повертає до вибраної глибини й 100%; PNG охоплює весь
поточний показ незалежно від камери.

## Запуск

У корені `E:\PETprojects\Rodovid`:

У Windows можна двічі клацнути `start-react-svg.bat`: він перевірить наявність середовища, за потреби встановить залежності та відкриє нову версію в браузері.

```sh
npm ci
npm run dev:react-svg
```

Адреса: <http://127.0.0.1:5175>. Початкова сторінка перенаправляє до домашньої особи; прямі адреси `/tree/I1` та `/person/I2` працюють після перезавантаження.

```sh
npm run build:react-svg
npm run preview:react-svg
```

Готовий статичний сайт — `dist-react-svg/`, preview — <http://127.0.0.1:4175>. На іншому статичному хостингу для маршрутів потрібне перенаправлення невідомих HTML-адрес до `index.html`, як і для основного сайту.

## Архітектура

- `src/edition/AtlasApp.tsx` — новий інтерфейс, покажчик і маршрути.
- `src/edition/AtlasApp.module.css`, `theme.css` — ізольоване оформлення нової точки входу.
- `src/edition/main.tsx` — окрема точка входу React.
- `vite.react-svg.config.ts` — окремі порти, точка входу HTML та каталог збірки.
- Спільні `src/graph/`, `src/room/`, `src/data/` і `src/navigation/` — граф, SVG, D3-жести, архів і перевірені дані.
- `src/graph/tree-layout.ts` — геометрія прямих гілок; `relatives-projection.ts`
  і `relatives-layout.ts` — пов'язаний граф та рядки вертикального родоводу з
  боковими гілками. `FamilyTree.tsx` містить спільні взаємодії й експорт;
  `HorizontalTree` і `VerticalTree` вибирають орієнтацію.

React створює SVG, TypeScript обчислює проєкцію родинного графа, `d3-selection` та `d3-zoom` керують камерою. Окремий конфіг Vite підміняє точку входу під час обробки HTML; вихідний `index.html` і команди основної версії залишаються придатними для її запуску.

Немає другого GEDCOM чи ручної копії `family.json`: обидві версії використовують ту саму конвертацію й валідацію. Жодних додаткових залежностей. Це локальна версія; публікація та захист архіву залишаються в релізному плані проєкту.

## Перевірки

```sh
npm run typecheck
npm run lint
npm run test:e2e:react-svg
```

Окремі Playwright-сценарії перевіряють desktop і Pixel 7: пошук, зміну центру, кімнати, прямі адреси, reload, масштаб, «До мене», повернення зі збереженим масштабом, порожній пошук, невідому людину й ширину 320 px. Браузерна емуляція не замінює приймання на фізичному телефоні.

Результат 11.10.2026: перевірка типів і статична збірка успішні; 30 предметних тестів графа, стану навігації та пошуку пройшли. Фінальний Playwright-прогін — 4/4, 41,8 с; додатково перевірені вміщення всіх вузлів у SVG, унікальність DOM ID та фокус заголовка після входу до кімнати. Знімки — `tmp/react-svg-desktop.png` і `tmp/react-svg-mobile.png`; desktop/mobile інтерфейс переглянуто в браузері. Vite повідомляє про основний JS-пакет понад 500 kB, як і в основній версії; архівні переглядачі зберігають наявне відкладене завантаження.
