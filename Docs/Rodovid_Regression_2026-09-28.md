# ROD-028 — локальна регресія, мобільний перегляд і доступність

Дата: 28.09.2026. Виконавець: Codex. Вихідний коміт: `f4e051f`.
Статус: **На перевірці** — локальна автоматизація виконана; фізичний телефон
і приймання реального контенту ROD-026 ще потрібні. Публікація не виконувалась.

## Набір і середовище

- Windows, Node.js 24.18.0, npm 11.16.0, Playwright 1.63.0, Chromium 153.0.8010.12.
- Desktop Chrome та **емуляція** Pixel 7; додаткові viewport 320×900 і 1024×900.
  Це два профілі одного рушія, а не перевірка Android/iOS чи Safari.
- Production build + `vite preview` на loopback `127.0.0.1:4174`, 2 workers,
  без throttling CPU/мережі. Відкрито домашню карту також у браузері Codex.
- Поточний сімейний набір: **45 людей, 71 зв’язок, 68 подій, 111 тверджень,
  32 місця**, 21 сімейний запис. Джерел, медіафайлів, доказових прив’язок
  і спогадів у підготовленому JSON немає. Перевірено всі 45 центрів і кімнат,
  а не лише історичні 25 із ТЗ.
- Початкова глибина відповідає [уточненню власника від 22.09](Rodovid_Radial_Map_v1.md):
  максимум для обраного центру (I1 — 6), технічне налаштування — 11.
  Давня вимога трьох початкових поколінь замінена цим рішенням; перемикання
  на три покоління залишається доступним і перевіряється.
- Синтетичні фото, PDF, аудіо, координати й альтернативи перехоплюються
  лише у тестовому браузері або готуються в ізольованих тестових папках.
  Вихідний `Data/` не змінено, ці матеріали не додано до сімейного `dist/`.

## Доступність і огляд

- Усі 45 центрів перевірені на 320/1024 px: повні SVG-імена/дати,
  ширина підписів, відповідність появ і зв’язків графу, доступний список
  та відсутність горизонтального прокручування сторінки.
- Для всіх 45 центрів на 320 px окремо виміряні цілі основної навігації,
  масштабу, поколінь, текстових альтернатив секторів і покажчика: мінімум
  **44×44 CSS px**. Це не заява, що кожен SVG-сектор має такий розмір
  за будь-якого масштабу; для щільної карти є рівнозначні текстові дії.
- Enter/Space, фокус після перебудови/входу в кімнату, Tab у діалозі,
  Escape і повернення до кнопки перевірені. Нативний dialog може включати
  прокручуване тіло у Tab-порядок; тест не нав’язує неіснуючий порядок.
- Reduced motion: системне й ручне налаштування, зміна під час анімації.
- Синтетичне довге ім’я без пробілів і розмір тексту 200% при 320 px:
  немає переповнення; це перевірка text resize, а не браузерного page zoom.
- Переглянуто знімки I1 на 320 px, I20 на 1024 px, вміщеного I1 на обох
  ширинах, діалогу з текстом 200% та мобільного PDF 200%.
  За поточним дизайном карта спочатку має читабельний шрифт 14 px і може
  виходити за полотно; доступні pan і «Вмістити карту». Після вміщення
  щільного дерева текст стає дрібним — потрібен zoom або список імен.
  PDF при 200% прокручується всередині переглядача, кнопка закриття видима.
- Повний аудит скринрідерами та сертифікація WCAG не виконувалися.

## Завантаження й швидкодія

[regression.spec.ts](../tests/e2e/regression.spec.ts) перевіряє production-запити:
`PlacesMap`, `PdfViewer`, PDF worker і сам PDF відсутні до відкриття;
після натискання відповідний код завантажується. Фото-тест окремо перевіряє,
що повні зображення не завантажуються до галереї. Мережеві помилки JSON,
PDF, фото, аудіо та тайлів мають перевірені доступні стани відмови.

Є попередження Vite про пакет понад 500 kB: основний JS приблизно 566 kB,
PDF viewer 433 kB, worker 1,27 MB, PlacesMap 151 kB (без gzip).
PDF worker і географічна карта відкладені. Це залишковий ризик для повільних
телефонів, не результат вимірювання на фізичному пристрої.
`center-readiness.json` містить 45 вимірювань на профіль від початку `goto`
до появи правильного SVG-центру. Це локальний wall time, не Web Vitals.

| Профіль, 320×900 | Карт | Медіана | p95 | Максимум |
| --- | ---: | ---: | ---: | ---: |
| Chromium desktop | 45 | 480 ms | 750 ms | 1273 ms |
| Pixel 7, емуляція Chromium | 45 | 486 ms | 1008 ms | 1063 ms |

Результати залежать від навантаження локального ПК; мобільна емуляція
використовує його процесор. Ці значення не прогнозують час фізичного телефона.

## Незавершене приймання фізичного телефона

Результат: **не виконано**, доступного фізичного пристрою для цього проходу немає.
Власник/тестувальник має записати модель, ОС, браузер/версію, дату, адресу
перевіреної збірки, мережу та фактичний результат кожного пункту.
До захищеної публікації перевіряти лише в довіреній локальній мережі;
інтернет-доступ до сімейного набору не вмикався.

| Дія на фізичному телефоні | Очікуваний результат | Фактичний результат |
| --- | --- | --- |
| Вибрати сектор і запис зі списку, повернутися «До мене» | Правильний центр, I1 залишається домашньою особою | Не перевірено |
| Pan одним пальцем, pinch двома; свайп поза картою | Камера рухається без випадкового переходу; сторінка прокручується поза полотном | Не перевірено |
| Вмістити карту, змінити покоління, згорнути/розгорнути гілку | Усі дії доступні без hover, покажчик повний | Не перевірено |
| Відкрити кімнату, двері й вибір кількох родичів; Назад | Коректні адреси, діалог закривається, історія збережена | Не перевірено |
| Збільшити реальний скан, прочитати дрібний запис; відкрити PDF/книгу | Читабельність при zoom, pan без втрати керування | Очікує також ROD-026 |
| Увімкнути музику й ефект натисканням, mute; відмова/помилка файла | Канали незалежні, mute працює, навігація не блокується | Очікує також матеріали ROD-026 |
| Повторити з повільним з’єднанням і reduced motion | Є стани завантаження/помилок, немає блокування навігації | Не перевірено |

Автентифікація, захист прямих адрес файлів, вихід і завершення сесії
залишаються обов’язковими для ROD-029…034. Локальна регресія не замінює
ці перевірки й не є дозволом на публікацію.
