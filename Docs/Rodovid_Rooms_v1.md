# Кімнати та архів

## Події — ROD-017

`src/room/biography.ts` форматує компоненти історичної дати без JavaScript Date та перерахунку календарів. Неповні дати, приблизність, межі й оригінальний запис залишаються видимими.

Порядок: основне твердження дати, числові рік/місяць/день; відсутні компоненти мають нуль лише у ключі сортування. Для інтервалу — початок або єдина наявна межа. Це порядок показу, а не твердження про хронологічну першість перетинних інтервалів. Без основної дати, з фразою або іншим календарем — наприкінці; однакові ключі впорядковано за ID. Альтернативи не переписують основний факт.

D01–D02 залишають окремі події з власними ID та походженням; шлюб не утворює нові зв’язки батьківства. `_EVDEF` не належить до масиву подій. Матеріали відкриваються за спільним mediaId; повний архівний переглядач додається в ROD-021.

## Спогади — ROD-019

Конвертер підтримує `memories` з Markdown у JSON та `memoryFiles` у файлі доповнень: ті самі id/personIds/title/provenance, але `markdownFile: "memories/example.md"` замість `markdown`. Шлях відносний до папки доповнень; файл читається лише поза браузером, має лишатися в цій папці, втрата файла блокує збірку. Автоматичного перетворення довільних GEDCOM-приміток на спогади немає: потрібне явне тематичне зіставлення.

Для відображення використано react-markdown 10.1.0, перевірено 2026-09-13 за [офіційним README](https://github.com/remarkjs/react-markdown). HTML пропускається, базові елементи дозволено явним списком, небезпечні URL проходять стандартне очищення, зовнішні посилання відкриваються окремо. Спогади не змінюють claims. Тестовий Markdown лежить тільки в tests/fixtures.
