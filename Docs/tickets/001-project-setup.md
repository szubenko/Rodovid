## Мета

Підготувати відтворюваний локальний запуск статичного застосунку в репозиторії Rodovid.

## Обсяг роботи

- Створити основу React + TypeScript + Vite, CSS Modules і CSS variables; зберегти наявні Docs/ та Data/.
- Перевірити сумісні стабільні версії рекомендованого стеку під час реалізації; зафіксувати Node.js, package-lock.json і команди npm ci, dev, build, preview.
- Налаштувати TypeScript, ESLint, Vitest і Playwright для подальших предметних перевірок; важкі бібліотеки додавати разом із відповідними функціями.
- Описати локальний запуск і виключити тимчасові файли та результати збірки з контролю версій.

## Критерії приймання

- [x] Після npm ci порожній застосунок запускається локально та збирається у dist/.
- [x] Перевірки типів і lint проходять; команди майбутніх тестів налаштовані без фіктивних тестів.
- [x] Версії та команди задокументовані; власний API і серверна база не потрібні.
- [x] Data/Zubenko.ged, Data/Zubenko.rmtree та вихідна документація збережені.

## Перевірка

Виконати чисте встановлення, перевірку типів, lint, build і локальний preview; записати результати команд.

Виконано Codex 2026-09-09. Створено локальний каркас зі стартовою українською сторінкою, CSS Modules і CSS variables, строгим TypeScript, ESLint, Vitest та Playwright. Команди, структура, точні версії й порядок подальших тестів описані в [README](../../README.md). Залежності зафіксовано в [package.json](../../package.json) і [package-lock.json](../../package-lock.json); Node.js 24.18.0 і npm 11.16.0 перевіряються через `engines` та `.npmrc`.

Стек: React 19.2.8, Vite 8.2.2, TypeScript 6.0.3, ESLint 10.10.0, typescript-eslint 8.70.0, Vitest 5.0.0, Playwright 1.63.0. Версії, `engines` та `peerDependencies` звірено з офіційним реєстром npm. TypeScript 7.0.2 свідомо не використано: typescript-eslint 8.70.0 підтримує `>=4.8.4 <6.1.0`. Примусове обходження peer-вимог не застосовувалося.

Особливість середовища перевірки: npm потребував дозволеного доступу до мережі. Повний запуск Playwright у Windows-пісочниці зависав після старту сервера; повтор поза пісочницею підтвердив успішний старт і зупинку дерева процесів. Обхід у коді проєкту не додавався.

Блокерів немає. Предметні тести й браузерні сценарії ще не створено; поточні запуски перевіряють лише інструменти. Після появи перших тестів відповідного набору потрібно прибрати дозволи на порожні набори з npm-команд. Встановлення Chromium для майбутніх E2E-сценаріїв описане в README. Карта, дані, маршрутизація й публікація залишаються в межах своїх тікетів. Наступний — [ROD-002](002-data-contract.md).
