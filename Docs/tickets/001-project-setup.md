## Мета

Підготувати відтворюваний локальний запуск статичного застосунку в репозиторії Rodovid.

## Обсяг роботи

- Створити основу React + TypeScript + Vite, CSS Modules і CSS variables; зберегти наявні Docs/ та Data/.
- Перевірити сумісні стабільні версії рекомендованого стеку під час реалізації; зафіксувати Node.js, package-lock.json і команди npm ci, dev, build, preview.
- Налаштувати TypeScript, ESLint, Vitest і Playwright для подальших предметних перевірок; важкі бібліотеки додавати разом із відповідними функціями.
- Описати локальний запуск і виключити тимчасові файли та результати збірки з контролю версій.

## Критерії приймання

- [ ] Після npm ci порожній застосунок запускається локально та збирається у dist/.
- [ ] Перевірки типів і lint проходять; команди майбутніх тестів налаштовані без фіктивних тестів.
- [ ] Версії та команди задокументовані; власний API і серверна база не потрібні.
- [ ] Data/Zubenko.ged, Data/Zubenko.rmtree та вихідна документація збережені.

## Перевірка

Виконати чисте встановлення, перевірку типів, lint, build і локальний preview; записати результати команд.
