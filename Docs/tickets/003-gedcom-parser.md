## Мета

Підтвердити, що обраний парсер правильно читає наданий експорт RootsMagic GEDCOM 5.5.1.

## Обсяг роботи

- Перевірити read-gedcom як кандидата на Data/Zubenko.ged; зафіксувати версію, підтримані конструкції та потрібний адаптер.
- Зберегти сирі ідентифікатори, українські/історичні імена, сімейні посилання, дати, місця і FamilySearch ID.
- Порівняти результат із оглядом даних; невідомі розширення збирати для майбутнього звіту.
- Якщо кандидат втрачає потрібні відомості, описати конкретну проблему й обґрунтувати сумісний варіант перед подальшим перетворенням.

## Критерії приймання

- [x] Незмінений базовий файл дає 25 людей, 9 сирих сімей і 48 сирих подій: 22 народження, 22 смерті, 4 шлюби.
- [x] Збережено 25 FamilySearch ID і 32 сирі прив’язки дітей до сімей; повтори не приховано.
- [x] 65 записів _EVDEF не стали подіями життя; SOUR RootsMagic не став історичним доказом.
- [x] Ім’я @I1@ відтворене як «Сегрій»; файл не переписаний і перехід на GEDCOM 7 не потрібний.
- [x] Є короткий висновок про придатність парсера з переліком обмежень.

## Перевірка

Запустити автоматичну звірку базових кількостей і вибірково перевірити вихідні записи, Unicode та посилання.

## Результат і блокери

Виконано Codex 2026-09-09. `read-gedcom 0.3.2` зафіксовано в devDependencies
і lockfile; [адаптер](../../scripts/gedcom/parse.ts) зберігає сире дерево,
ID, Unicode, дати, місця й усі повтори. [Висновок та обмеження](../Rodovid_Gedcom_Parser_Review_2026-09-09.md).

`npm run data:check-gedcom` підтвердила всі контрольні кількості, 1156 рядків
без втрат і SHA-256 з огляду. Звіт розширень відтворюється в
`tmp/gedcom-probe.json`. Пройшли 53 тести (12 для парсера), `npm run typecheck`,
`npm run lint`, `npm run build`. Вхідні GEDCOM/RootsMagic не змінені.

Блокерів немає. D01–D06 залишені для ROD-004; нормалізація дат, джерел,
медіа й інших типів подій та перевірка графа належать ROD-005/006.
