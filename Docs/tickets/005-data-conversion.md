## Мета

Отримувати підготовлений JSON із GEDCOM, налаштувань і матеріалів без ручного дублювання родоводу.

## Обсяг роботи

- Реалізувати команду перетворення до узгодженої моделі; зберігати походження людей, сімей, подій і зв’язків.
- Додати налаштування, пояснення/оцінки, альтернативні твердження, джерела, прив’язки доказів і спогади відповідно до правил моделі.
- Застосовувати лише явне зіставлення ID; не з’єднувати людей автоматично за однаковим ім’ям.
- Підтримати неповні дати й різні типи подій; батьківство отримувати з явних вихідних зв’язків, а не виводити зі шлюбу.

## Критерії приймання

- [x] JSON містить усіх 25 людей базового набору та домашню особу I1; зміни після ручного виправлення окремо пояснені.
- [x] Повторні запуски з однаковим входом дають однаковий зміст; джерело не змінюється.
- [x] На окремих прикладах збережені альтернативи, джерела, оцінки, нотатки та кілька прив’язок одного документа.
- [x] Явне перепризначення ID зберігає матеріали й налаштування; відсутнє зіставлення не спричиняє тихої втрати.
- [x] Відсутні у реальному експорті фото, докази, координати та спогади залишаються відсутніми.

## Перевірка

Vitest для перетворення реального файлу та синтетичних складних прикладів; перевірити повторний експорт зі зміненими ID.

## Результат і блокери

Виконано Codex 2026-09-09. Додано `npm run data:convert`,
[конвертер](../../scripts/gedcom/convert.ts),
[журнал 254 стабільних ID](../../Data/identities.json),
[доповнення D01–D06](../../Data/annotations.json) та
[інструкцію](../Rodovid_Data_Conversion_v1.md).

Результат у `generated/family.json`: 25 людей, домашня I1, 71 зв’язок,
48 подій, 77 тверджень і 24 входження місць (8 різних вихідних текстів).
У журналі/звіті збережені всі 9 сирих сімей і 32 прив’язки дітей.
Фото, історичні джерела, докази, координати й спогади не вигадані.
Доповнення містять 62 пояснення до зв’язків/тверджень і 24 до місць;
достовірність залишається `unassessed`, проблемні зв’язки — `unreviewed`.

Перевірено: 99 тестів Vitest (6 файлів), lint, типи та збірка;
`data:check-gedcom` підтвердив SHA-256, усі 1156 рядків і базові кількості.
Повторна CLI-конвертація дала побайтово однакові JSON і звіт.
Синтетичні приклади перевіряють альтернативи, нотатки, джерела, QUAY,
спільний документ, зміни XREF/порядку подій, збереження налаштувань і
матеріалів та помилки відсутнього зіставлення/прив’язки. Контрольні суми
GEDCOM і RootsMagic незмінені. `git diff --check` пройшов.

Блокерів немає. Історичні уточнення D01–D06 залишаються за власником.
Звіт містить неперетворені структури (у базовому наборі — 25 `SEX`);
повна предметна валідація, правила блокування збірки, перевірка/копіювання
фізичних медіафайлів та інтеграція JSON зі збіркою — ROD-006/007.
