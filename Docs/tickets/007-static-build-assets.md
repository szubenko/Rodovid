## Мета

Збирати тільки потрібні браузеру файли та відтворювано готувати матеріали.

## Обсяг роботи

- Об’єднати підготовку, валідацію й Vite build у npm run build; передбачити локальний preview.
- Копіювати оголошені матеріали з постійних папок проєкту, зберігаючи спільний файл для кількох прив’язок.
- Визначити мініатюри, повні зображення й окремі архівні оригінали; скани зберігати читабельними.
- Включати до dist/ тільки результат застосунку, JSON і потрібні матеріали; виключити GEDCOM, RootsMagic, робочі звіти та тестові набори.

## Критерії приймання

- [x] Одна команда перевіряє дані й створює локально працездатний статичний результат.
- [x] Помилка валідації зупиняє збірку; відсутній необов’язковий контент допускає порожній стан.
- [x] У dist/ немає .ged, .rmtree, вихідного архіву, робочих звітів або синтетичних сімейних прикладів.
- [x] Посилання на матеріали не залежать від абсолютних шляхів Windows чи тимчасової папки завантажень.
- [x] Повторна збірка після заміни входу показує нову версію; попередні матеріали не залишаються випадково у результаті.

## Перевірка

Переглянути склад dist/, пройти всі локальні посилання та перевірити збірку з порожнім і тестовим набором матеріалів.

## Результат і блокери

Виконано Codex 2026-09-09. [Правила збірки й матеріалів](../Rodovid_Static_Build_v1.md):

- `npm run build` перевіряє типи, заново конвертує й валідує вхід та збирає застосунок, `data/family.json` і лише оголошені матеріали. Прямий Vite build також запускає підготовку; dev і preview підтримують локальні URL.
- Додано необов’язкову JPEG/PNG-мініатюру для зображення чи PDF; основні файли та мініатюри перевіряються й копіюються без перекодування. Архівні оригінали зберігаються окремо. Спільний шлях дає один файл; колізії регістру блокуються.
- Перевірено відсутній файл, хибну мініатюру, замасковане розширення, повторну збірку, побайтову заміну матеріалу, нову версію входу й очищення вилучених матеріалів. Синтетичні збірки виконуються в ізольованих тимчасових папках.
- Пройшли 140 тестів Vitest, TypeScript, ESLint і збірка; обидва Playwright-сценарії (Chromium desktop / Pixel 7) підтвердили екран, JSON та локальні посилання через preview. Для перевірок установлено Chromium; таймаут двох наявних CLI-тестів збільшено до 30 секунд для паралельного запуску.
- Фактичний `dist/`: `index.html`, JS/CSS у `app-assets/`, `data/family.json` (25 людей, 48 подій). Неоголошених матеріалів, тестових наборів, вихідних архівів, звітів і абсолютних Windows-шляхів у JSON немає. Дані мають 0 помилок і 34 відомі попередження; GEDCOM/RootsMagic незмінені.

Блокерів немає. Реальні фото/скани ще не надані; оцінка їхньої читабельності залишається в ROD-026. Мініатюри готуються поза збіркою, що описано в інструкції. Публікація не виконувалася.
