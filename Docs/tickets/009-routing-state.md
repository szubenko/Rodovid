## Мета

Зв’язати адреси карти й кімнат зі спільним станом перегляду та підготовленими даними.

## Обсяг роботи

- Додати React Router у declarative mode, /tree/:personId, /person/:personId і початковий перехід до домашньої особи.
- Завантажувати та перевіряти підготовлений JSON; передбачити стани завантаження, помилки й невідомого personId.
- Відділити homePersonId, центр, тип екрана, вибір зв’язку й параметри карти; використати Context/useReducer відповідно до стеку.
- Визначити політику історії; робочий варіант між відвідуваннями — починати з I1, доки відновлення останньої позиції окремо не погоджене.

## Критерії приймання

- [ ] Локальні прямі адреси карти й кімнати відкривають відповідну людину.
- [ ] Перший вхід починається з I1, а зміна центру не змінює homePersonId.
- [ ] Невідомий ID або помилка даних показує зрозумілий стан і доступну дію повернення.
- [ ] Переходи не завантажують родовід повторно без потреби; сімейні дані не записуються у localStorage.
- [ ] Поведінка після перезавантаження та нового відвідування задокументована.

## Перевірка

Перевірити прямі адреси, неправильний ID, помилку завантаження й повторне відкриття; серверні rewrites перевіряються на етапі публікації.
