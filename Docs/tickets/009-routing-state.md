## Мета

Зв’язати адреси карти й кімнат зі спільним станом перегляду та підготовленими даними.

## Обсяг роботи

- Додати React Router у declarative mode, /tree/:personId, /person/:personId і початковий перехід до домашньої особи.
- Завантажувати та перевіряти підготовлений JSON; передбачити стани завантаження, помилки й невідомого personId.
- Відділити homePersonId, центр, тип екрана, вибір зв’язку й параметри карти; використати Context/useReducer відповідно до стеку.
- Визначити політику історії; робочий варіант між відвідуваннями — починати з I1, доки відновлення останньої позиції окремо не погоджене.

## Критерії приймання

- [x] Локальні прямі адреси карти й кімнати відкривають відповідну людину.
- [x] Перший вхід починається з I1, а зміна центру не змінює homePersonId.
- [x] Невідомий ID або помилка даних показує зрозумілий стан і доступну дію повернення.
- [x] Переходи не завантажують родовід повторно без потреби; сімейні дані не записуються у localStorage.
- [x] Поведінка після перезавантаження та нового відвідування задокументована.

## Перевірка

Перевірити прямі адреси, неправильний ID, помилку завантаження й повторне відкриття; серверні rewrites перевіряються на етапі публікації.

## Результат і блокери

Реалізовано React Router 8.3.1 у declarative mode, `/tree/:personId`,
`/person/:personId`, початковий перехід до I1, базові екрани та покажчик усіх
25 людей. Завантаження має спільний Promise, Zod-перевірку й стани помилок
із повторною спробою. Context/useReducer відділяє домашню особу, центр,
екран, вибір зв’язку та параметри карти; Back/Forward відновлює знімки поточного
перегляду. [Політика адрес, історії, reload і нового входу](../Rodovid_Navigation_v1.md).

Перевірено: типи й збірка через `npm run test:e2e`, `npm run lint`,
`npm test` — 154/154; Playwright — 20/20 у desktop/mobile Chromium,
зокрема прямі адреси, reload, невідомі ID, затримка/помилки даних, retry,
один запит, відсутність browser storage і клавіатура на 320 px.
Чотири знімки карти/кімнати з `test-results/` переглянуто візуально.
Після виконання тестів локальний preview-процес довелося завершити окремо:
автоматичне прибирання Playwright зависало в цьому Windows sandbox;
повторний запуск завершився кодом 0 з 20 успішними тестами.
`npm run data:check-gedcom` підтвердив SHA-256, 1156 рядків і базові кількості.
GEDCOM/RootsMagic та інші файли Data/ незмінені.

Блокерів немає. Повна карта, жести, анімації та вміст кімнат належать
наступним тікетам; rewrites на хостингу й захист адрес — релізному етапу.
