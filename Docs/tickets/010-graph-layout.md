## Мета

Побудувати стабільне радіальне розташування видимої частини родоводу без втрати людей і змісту зв’язків.

## Обсяг роботи

- Відокремити повний граф від екранної проєкції; додати чисті TypeScript-функції розкладки.
- Розміщувати батьків, подружжя, дітей і бічні гілки за правилами прототипу; шлюб сам по собі не додає покоління.
- Використати personId для сутності й окремий ID екранної появи; зберігати стабільний порядок гілок.
- Обмежити обходи циклів і повторів; врахувати глибину та згортання без зміни вихідного графа й автоматичного злиття сімей.

## Критерії приймання

- [x] Для I1 є проєкція початкових трьох поколінь; інші центри дають доступ до старших і бічних гілок.
- [x] Усі 25 людей досяжні послідовними переходами.
- [x] Повторні появи однієї людини мають спільний personId та різні екранні ID.
- [x] Цикли, D01–D03 і неповні сім’ї не спричиняють зависання чи тихого виправлення даних.
- [x] Однаковий вхід дає стабільне розташування; вузли мають скінченні координати та враховують розмір підписів.

## Перевірка

Vitest для реального графа, повторного предка, циклу, кількох подружніх зв’язків і різної глибини; огляд геометрії на двох розмірах екрана.

## Результат і блокери

Реалізовано [проєкцію](../../src/graph/projection.ts) і
[геометрію](../../src/graph/layout.ts). [Контракт і правила](../Rodovid_Graph_Layout_v1.md)
описують покоління/кільця, стабільні ID, збереження зв’язків D01–D03,
обмеження обходу, згортання та підписи. Початкова I1 має п’ять появ;
переходами між видимими людьми досяжні всі 25 записів, доступні всі 71 зв’язок.

Додано 22 предметні тести: реальний GEDCOM, повторний предок, цикли, кілька
подружніх зв’язків, неповні/дубльовані сім’ї, глибина, згортання й ліміт.
Для всіх центрів на 320/1024 px перевірено скінченні координати, відсутність
перекриття секторів одного кільця та підписи. Шість локальних знімків I1/3,
I9/3, I20/4 переглянуто; браузер не знайшов виходу тексту за виділену ширину.
Відтворення: `npm run data:convert`, `node scripts/review-graph.ts`;
HTML/PNG та звіт — `tmp/rod010/`.

176 модульних і 20 браузерних тестів, типи, lint і збірка пройшли; контрольна
звірка GEDCOM успішна. Playwright поза sandbox завершився з кодом 0; два
попередні запуски в sandbox пройшли сценарії, але зависли на завершенні сервера
й були зупинені. Дані та залежності незмінені. Повні дугові підписи не вміщуються
в усі щільні сектори; повне ім’я збережено для доступних назв і списку.
React-відображення належить ROD-011, жести/масштаб — ROD-013, повний аудит
інтерфейсу — ROD-028.
