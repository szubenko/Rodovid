## Мета

Показати робочу радіальну карту з читабельними людьми та інтерактивними зв’язками.

## Обсяг роботи

- Відмалювати вузли й лінії в SVG під керуванням React; застосувати d3-shape для геометрії за потреби.
- Додати ім’я, відомі роки життя, фото/заглушку, виділення центру та ознаку прихованих родичів.
- Розділити SVG-групи камери й координат вузлів для подальших жестів та анімацій.
- Передбачити вибір людини й лінії мишею, клавіатурою та дотиком; зберігати ID вибраного зв’язку для доказів.

## Критерії приймання

- [ ] Початковий екран показує I1 у центрі та родичів відповідно до проєкції.
- [ ] На вузлах немає вигаданих дат, фотографій або порожніх технічних значень.
- [ ] Центр і вибір розрізняються візуально; основні підписи читаються на телефоні.
- [ ] Вибір лінії визначає конкретний родинний зв’язок; область натискання придатна для дотику.
- [ ] Фокус видно, елементи мають зрозумілі доступні назви.

## Перевірка

Переглянути карту на реальному наборі з довгими іменами та без фото; перевірити клавіатурний вибір вузла й зв’язку.
