## Мета

Дати змогу зручно досліджувати карту мишею та дотиком, керуючи кількістю видимих родичів.

## Обсяг роботи

- Додати d3-zoom, переміщення, pinch-to-zoom і видимі кнопки масштабу/повернення у видиму область.
- Додати згортання/розгортання гілок, обмеження поколінь та зрозуміле позначення прихованого продовження.
- Узгодити жести карти з вибором вузлів, сторінковим прокручуванням і анімаціями центру.
- Застосувати поведінку відновлення параметрів, визначену в ROD-012.

## Критерії приймання

- [x] Масштаб і переміщення працюють мишею, кнопками й дотиком.
- [x] Гілка згортається та розгортається; індикатор пояснює наявність прихованих родичів.
- [x] Зміна глибини не видаляє людей з повного набору й пошуку.
- [x] Після зміни розміру екрана або центру карта залишається доступною; є спосіб повернути її у видиму область.
- [x] Жест переміщення не відкриває випадково людину, а основні дії не залежать від hover.

## Перевірка

Перевірити жести в мобільному браузері й на справжньому телефоні; пройти згортання, розгортання, зміну глибини та повернення.

## Результат і блокери

2026-09-13, Codex: реалізація готова, п’ять критеріїв підтверджено автоматичними
перевірками та локальним оглядом. **На перевірці**, оскільки зазначений вище
прогін на фізичному телефоні ще не виконаний; емуляція його не замінює.

- [RadialMap](../../src/graph/RadialMap.tsx), [камера d3-zoom](../../src/graph/useMapCamera.ts)
  і [масштабування](../../src/graph/camera.ts): 50–600%, перетягування,
  pinch, Ctrl + колесо, доступні кнопки переміщення й «Вмістити карту».
- Покоління 1–12 і згортання за appearanceId; приховане продовження має
  пояснення. Усі 25 людей залишаються в повному наборі та покажчику.
  Пошук у ROD-014 має використовувати цей повний набір, а не проєкцію.
- Параметри відновлюються через Back/Forward і кімнату; «До мене» скидає
  домашній вигляд. Нормалізований pan зберігає позицію після resize.
  Камера й координати секторів мають окремі transform; втручання в перехід
  одночасно завершує рух вузлів і ліній. Подробиці — у
  [документації навігації](../Rodovid_Navigation_v1.md#керування-картою--rod-013).
- Виправлено горизонтальне переповнення на вікні 320 px зі звичайною смугою
  прокрутки та нестабільне читання заголовка до завершення маршрутизації в тесті ROD-009.

Перевірено:

- `npm test`: 193/193; `npm run lint`, типи та production build — успішні.
- `npm run test:e2e`: 53 успішні, 1 очікуваний пропуск touch-сценарію в
  desktop-профілі. На mobile Chromium цей сценарій пройшов: нативні CDP-події
  drag/pinch, відсутність випадкового переходу та прокручування поза картою.
  [Сценарії ROD-013](../../tests/e2e/map-controls.spec.ts) також покривають
  межі масштабу, згортання, глибину, історію, кімнату, resize і жести після reset.
- Візуально оглянуто керування, глибину 6, масштаб 125% та гілки на 320 px
  у локальному браузері. Після виправлення ширини scrollWidth = clientWidth = 305
  при viewport 320 зі смугою прокрутки. Автоматичні знімки `controls-320.png`
  зберігаються в `test-results/` для обох профілів.
- `npm run data:check-gedcom`: незмінні SHA-256, 1156 рядків, 25 людей,
  9 сімей, 48 подій. Початкові GEDCOM/RootsMagic не змінено.

Залишилося для приймання (власник / тестувальник із фізичним телефоном):
записати модель, ОС і браузер; пройти tap по сектору й лінії, drag без
відкриття кімнати, pinch, прокручування поза картою, згортання / розгортання,
зміну поколінь, поворот екрана, «Вмістити карту», «Назад» і «До мене».
