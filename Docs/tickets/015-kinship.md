## Мета

Пояснювати зв’язок обраної людини з власником із чесним показом невизначеності.

## Обсяг роботи

- Розраховувати шлях від постійного homePersonId, незалежно від поточного центру.
- Підтримати погоджені базові родинні ролі; для складнішого шляху показати зрозумілий ланцюжок людей і зв’язків.
- Враховувати непевні твердження та результати D01–D03; не обирати мовчки один із суперечливих шляхів.
- Додати стан відсутнього шляху та обмежити обхід циклів.

## Критерії приймання

- [ ] Зміна центру не змінює точку відліку пояснення — власника I1.
- [ ] На перевірених прикладах правильно показані батьки, предки, діти й бічні зв’язки.
- [ ] Шлях через невирішений D01–D03 не отримує безумовного точного підпису; причина невизначеності видима.
- [ ] Кілька суперечливих шляхів або відсутність шляху пояснені без вигаданого споріднення.
- [ ] Повторні предки й цикли не спричиняють нескінченного пошуку.

## Перевірка

Vitest для основних ролей, неоднозначного шляху, ізольованої людини й циклу; реальні проблемні зв’язки перевірити за реєстром.
