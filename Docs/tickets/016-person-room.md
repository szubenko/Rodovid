## Мета

Створити адаптивну персональну кімнату, що об’єднує відомості та переходи людини.

## Обсяг роботи

- Реалізувати 2D-сцену з читабельним HTML-вмістом: імена, альтернативи, стать за наявності, життєпис. Фото — додатковий матеріал за наявності; за його відсутності не створювати велику заглушку чи резервувати портретну область.
- Підготувати місця для біографії, спогадів, архіву, карти місць і дверей до родичів.
- Додати видиму дію входу з родинної карти та повернення до карти з узгодженою історією.
- Для вузького екрана перейти до вертикального компонування; порожні розділи пояснювати без форм введення.

## Критерії приймання

- [x] Кімната доступна для кожного з 25 personId, зокрема через пряме посилання.
- [x] Повторні зображення людини на карті відкривають одну кімнату.
- [x] Невідомі поля не заповнюються вигаданими значеннями; відсутня дата смерті не означає «живий».
- [x] На телефоні текст читається без горизонтального прокручування, навігація залишається доступною.
- [x] Вхід із карти, повернення й історія браузера працюють; редагування та завантаження даних відсутні.

## Перевірка

Перевірити кімнату I1, людину з довгим ім’ям, без фото та з мінімумом біографії на широкому й вузькому екранах.
