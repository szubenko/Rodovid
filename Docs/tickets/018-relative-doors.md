## Мета

Дозволити переходи між кімнатами через батьків, подружжя та дітей.

## Обсяг роботи

- Побудувати три напрямки переходів із явно підготовлених зв’язків. За уточненням ROD-008 показувати їх компактним блоком імен/кнопок, без великих декоративних дверних панелей.
- Для кожного відомого батька показувати окрему кнопку з ім’ям із прямим переходом до кімнати. Для подружжя й дітей: один родич відкриває свою кімнату, кілька — доступний список вибору.
- Для відсутніх записів показати пояснення; не стверджувати, що родичів у житті не було.
- Додати базове відкриття дверей, зміну кімнати й повернення фокуса; фінальне оформлення та звук підключаються в наступних тікетах.

## Критерії приймання

- [x] Перехід до батьків, подружжя та дітей веде до правильного personId.
- [x] Список кількох родичів працює дотиком і клавіатурою, його можна закрити.
- [x] Нуль записів дає пояснення без пропозиції додати людину.
- [x] «Назад» повертає до попередньої кімнати, а повернення до карти узгоджене з поточною людиною.
- [x] Швидкі повторні натискання не дублюють переходи; зменшення руху не блокує навігацію.

## Перевірка

Playwright на випадках 0/1/кілька родичів; пройти ланцюжок кімнат і повернення до карти.
