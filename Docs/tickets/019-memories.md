## Мета

Показувати заздалегідь підготовлені історії про людину окремо від структурованих фактів.

## Обсяг роботи

- Завантажувати спогади з узгоджених нотаток GEDCOM або Markdown-файлів з явною прив’язкою до personId.
- Використати react-markdown для базового форматування без виконуваного HTML.
- Зробити читабельними довгі тексти та підготовлені посилання на телефоні.
- Додати порожній стан; автор/оповідач, аудіо та відео не розширюють обов’язковий обсяг v0.1.

## Критерії приймання

- [x] Підготовлений спогад відкривається в кімнаті потрібної людини з абзацами, списками та базовим форматуванням.
- [x] Текст спогаду не змінює оцінки достовірності фактів.
- [x] У реальному наборі без спогадів показаний коректний порожній стан.
- [x] Довільний HTML або виконуваний вміст не запускається.
- [x] Форм створення, редагування й видалення тексту немає.

## Перевірка

Перевірити довгий підготовлений текст, порожній розділ і приклад із забороненим HTML; тестовий спогад не публікувати як сімейний факт.

## Результат і блокери

Спогади з явними personIds і Markdown-файлами під час конвертації; react-markdown 10.1.0 завантажується лише за наявності тексту. HTML не виконується, посилання очищуються, оцінки фактів незмінні. Lint, 3 модульні та 2 браузерні тести, типи й збірка пройшли; браузерні тести повторно пройшли після поділу пакета. Довгий текст візуально перевірено. Сімейних спогадів поки немає.
