## Мета

Дати читабельний доступ до сканів метричних записів, PDF і зовнішніх джерел.

## Обсяг роботи

- Створити спільну картку документа: назва, опис, архівний шифр, сторінка/кадр, номер запису та підготовлена розшифровка.
- Використати переглядач зображень для JPG/PNG і PDF.js для PDF з відкладеним завантаженням.
- Додати підготовлені зовнішні посилання з назвою, описом і датою внесення, якщо вони є.
- Підтримати відкриття спільного документа з різних кімнат; не виконувати OCR чи синхронізацію сторонніх сервісів.

## Критерії приймання

- [x] Скрін можна збільшити й перемістити так, щоб читати дрібний запис на комп’ютері та телефоні.
- [x] PDF відкривається зі сторінками й масштабом; є пряме посилання на файл, захист якого перевіряється перед релізом.
- [x] Один documentId і один файл доступні з кімнат кількох людей.
- [x] Реквізити та розшифровка показуються тільки за наявності.
- [x] Недоступність зовнішнього джерела не заважає читанню вже завантажених відомостей і локального скану; FamilySearch ID не позначається як доказ.

## Перевірка

Перевірити JPG, PNG, багатосторінковий PDF, один документ для двох людей і недоступне зовнішнє посилання.
