## Мета

Дати власнику відтворюваний порядок ручного оновлення архіву та повернення до попередньої версії.

## Обсяг роботи

- Описати, де лежать GEDCOM, налаштування, доповнення, матеріали, згенеровані дані та звіт.
- Оформити послідовність: резервна копія → ручне оновлення → зіставлення ID за потреби → перевірка → build → локальний перегляд.
- Додати інструкцію читання помилок/попереджень, заміни матеріалів і виправлення неприв’язаних доповнень.
- Описати резервування вихідних даних і всіх матеріалів, відновлення та окреме зберігання архівних оригіналів.

## Критерії приймання

- [x] За інструкцією можна отримати локальну оновлену версію без редагування generated JSON.
- [x] Повторний експорт не втрачає людей, зв’язки, альтернативи, докази й матеріали; перепризначені ID мають явне зіставлення.
- [x] При помилці даних власник розуміє, який вихідний запис або файл виправити.
- [x] Відновлення перевірене на окремій копії та охоплює дані разом із матеріалами.
- [x] Інструкція не додає імпорт, експорт, редактор або кнопки резервування до сайту.

## Перевірка

Пройти інструкцію на копії: змінити підготовлений матеріал, повторно зібрати, перевірити результат і відновити попередній стан.

## Результат і блокери

2026-09-28: виконано. Додано [інструкцію](../Rodovid_Archive_Update_Guide.md)
з актуальними шляхами та командами, знімками SHA-256, явним зіставленням ID,
читанням діагностики, заміною матеріалів і відновленням у нову папку.
README містить посилання для власника. Код та інтерфейс сайту не змінювалися.

[Протокол перевірки](../Rodovid_Archive_Update_Check_2026-09-28.md):
на окремій копії змінено Markdown і PNG, зібрано й переглянуто нову версію,
відновлено всі 234 файли з перевіркою маніфесту, повторно виконано `npm ci`,
валідацію, typecheck/build та перевірку Chromium. Відновлені JSON і матеріал
побайтово відповідають початковим. Відсутній файл та неприв’язаний спогад
дають код 1 і конкретну діагностику; стара збірка не видається за нову.
30 профільних тестів пройшли, включно з повторними експортами, альтернативами
й доказами. Усі 5 файлів реального `Data/` залишилися незміненими.

ROD-006/007 виконано. Незавершений ROD-026 не перешкоджає завершенню
технічної інструкції: відсутні сімейні матеріали перевірено синтетично
лише в ізольованій копії. Реєстр і приймання релізного контенту залишаються
в ROD-026; там же записано виявлену потребу додати вхідну прив’язку портретів.
Повне резервування зовнішнього архіву на другий носій та відкриття
відновленої бази у RootsMagic цим прогоном не підтверджувалися.
