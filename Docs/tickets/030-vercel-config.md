## Мета

Підготувати конфігурацію Vercel для статичної збірки, прямих маршрутів і сімейних файлів.

## Обсяг роботи

- Налаштувати build command, dist/, версію Node.js і SPA rewrites у vercel.json для карти та кімнат.
- Зберегти коректну видачу JSON, зображень, PDF та аудіо; відсутні файли не підміняти HTML сторінкою.
- Задати Cache-Control: no-store для сімейних JSON і матеріалів, не підключати service worker або офлайн-кеш.
- Підготувати окремий нешкідливий набір HTML/JSON/зображення/PDF для першої публікації; перевірити приватність репозиторію, якщо сімейні джерела використовуються у віддаленій збірці.

## Критерії приймання

- [ ] Конфігурація відтворює локальну збірку та передбачає прямі /tree/I1 і /person/I1.
- [ ] Існуючі файли отримують правильний тип вмісту, відсутні — 404, а не HTML зі статусом 200.
- [ ] Сімейні JSON/матеріали мають заплановані no-store заголовки; постійного офлайн-кешу немає.
- [ ] Пакет першої перевірки містить тільки нешкідливі приклади без родинних даних.
- [ ] Вихідні GEDCOM, RootsMagic та звіти виключені з публічних ресурсів; спосіб доставки вихідних даних на збірку описаний.

## Перевірка

Перевірити результат build і правила маршрутів локально; фактичні заголовки та rewrites на Vercel перевірити в ROD-031.
