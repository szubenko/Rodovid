## Мета

Довести, що захист охоплює всі адреси й прямі файли повного сімейного деплою.
Власник 31.10.2026 явно скасував етап заглушки й обрав одразу всі підготовлені дані.

## Обсяг роботи

- Розгорнути повний сімейний атлас із Vercel Authentication / All Deployments відповідно до чинного рішення власника.
- Скласти матрицю production-домену, основної vercel.app адреси, preview, згенерованих URL і всіх інших активних aliases.
- Для кожної адреси перевірити HTML, прямий сімейний JSON, зображення, аудіо та PDF за його наявності без входу й після дозволеного входу.
- Виключити ненавмисні винятки доступу; перевірити rewrites, 404 і фактичні заголовки кешування.

## Критерії приймання

- [ ] Неавторизований і недопущений відвідувач не отримують захищений вміст за жодною перевіреною адресою.
- [ ] Дозволений відвідувач після входу отримує сторінку та файли.
- [ ] Матриця охоплює всі активні адреси, включно з production і preview; відсутність власного домену явно записана.
- [ ] JSON/PDF/зображення захищені перед видачею; приховування UI не використовується як контроль доступу.
- [ ] Зафіксовані результати перевірок, налаштування та версія коду/даних перевіреного сімейного деплою.

## Перевірка

Використати чисту/приватну сесію та дозволений обліковий запис; зберегти HTTP-результати без секретів, токенів і паролів.

## Результат і блокери

31.10.2026 власник скасував початкову заглушку й обрав одразу повний атлас.
Заглушку вилучено, [матрицю перевірок](../Rodovid_Vercel_Deployment.md)
переписано для реальних сторінок і матеріалів. Успішного фактичного деплою
й перевірки захисту ще не підтверджено: Vercel налаштовує власник.
Статус «Заплановано», 0/5; локальна перевірка CSP не доводить edge authentication.
