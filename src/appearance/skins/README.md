# Ілюстрації карток

`stylepicture.png` — зразок, наданий власником 2026-10-18 з
`E:/Download/stylepicture.png`. Оригінал збережений без змін. SVG-патерн
показує лише круглий портрет потрібного скіна; ім'я й дати рендеряться з
даних родоводу. Ілюстрація не є фотографією конкретної людини.

Дизайн увімкнений для всіх карток вертикального родоводу. Ілюстрації
використовують один спільний растровий ресурс, також під час експорту PNG.
Заняття має пріоритет перед станом; підтримані відповідники зразка —
козак/козачка, селянин/селянка й гончар/гончарка. За відсутності
однозначного відповідника використовується нейтральний скін за статтю.
Непідтверджена гіпотеза або участь у чужій події не визначає скін.
