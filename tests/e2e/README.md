# Наскрізні перевірки

Тут з’являтимуться `*.spec.ts` із перевірками поведінки відповідних тікетів.
ROD-001 налаштовує Playwright без фіктивних тестів.

`npm run test:e2e` збирає застосунок і запускає окремий preview на
`http://127.0.0.1:4174`. Конфігурація містить Chromium для комп’ютера й
мобільний профіль Pixel 7. Сліди та знімки зберігаються для невдалих тестів.

Перед першим реальним запуском: `npx playwright install chromium`.
Налаштування дозволяє нуль тестів через явний прапорець у npm-команді;
після додавання перших сценаріїв слід прибрати `--pass-with-no-tests`.
