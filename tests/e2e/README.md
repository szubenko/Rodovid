# Наскрізні перевірки

`static-build.spec.ts` перевіряє стартовий екран, доступність поточного
`data/family.json`, домашню особу, JS/CSS та всі оголошені матеріали й мініатюри.

`routing.spec.ts` перевіряє прямі адреси карти й кімнати, постійну домашню особу,
Back/Forward, reload та нове відвідування; одноразове завантаження, відсутність
записів у localStorage/sessionStorage, невідомі адреси, затримку, мережеві/HTTP
помилки й невалідні дані з повторною спробою. Окремо перевірено клавіатуру,
фокус після переходу та відсутність горизонтального переповнення на 320 px.
Сценарій історії зберігає знімки карти й кімнати в `test-results/` для перегляду.

`radial-map.spec.ts` перевіряє початкову проєкцію I1, перехід сектором і
клавіатурою, реальний дотик/клік по лінії, збереження вибору після повернення
з кімнати, окремі зв’язки D01–D03 та порожній набір відомостей.
Для всіх 25 центрів на 320/1024 px звіряє появи та ID зв’язків із проєкцією,
ширину SVG-підписів, повний список людей і відсутність горизонтального
переповнення. Зберігає карту та повний екран I1/I9/I20 на обох ширинах.
Окремий запуск: `npm run test:e2e -- tests/e2e/radial-map.spec.ts`.

`npm run test:e2e` збирає застосунок і запускає окремий preview на
`http://127.0.0.1:4174`. Конфігурація містить Chromium для комп’ютера й
мобільний профіль Pixel 7. Сліди та знімки зберігаються для невдалих тестів.

Перед першим реальним запуском: `npx playwright install chromium`.
Нуль тестів вважається помилкою. Синтетичні набори матеріалів перевіряються
окремо у Vitest через ізольовані тимчасові збірки й не потрапляють у `dist/` проєкту.
