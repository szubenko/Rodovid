# Наскрізні перевірки

`static-build.spec.ts` перевіряє стартовий екран, доступність поточного
`data/family.json`, домашню особу, JS/CSS та всі оголошені матеріали й мініатюри.

`routing.spec.ts` перевіряє прямі адреси карти й кімнати, постійну домашню особу,
Back/Forward, reload та нове відвідування; одноразове завантаження, відсутність
записів у localStorage/sessionStorage, невідомі адреси, затримку, мережеві/HTTP
помилки й невалідні дані з повторною спробою. Окремо перевірено клавіатуру,
фокус після переходу та відсутність горизонтального переповнення на 320 px.
Сценарій історії зберігає знімки карти й кімнати в `test-results/` для перегляду.

`radial-map.spec.ts` перевіряє початкову проєкцію I1, перехід сектором і
клавіатурою, реальний дотик/клік по лінії, збереження вибору після повернення
з кімнати, виправлене батьківство та позначку D09, а також порожній набір відомостей.
Для всіх 74 центрів на 320/1024 px звіряє появи та ID зв’язків із проєкцією,
ширину SVG-підписів, повний список людей і відсутність горизонтального
переповнення. Зберігає карту та повний екран I1/I9/I20 на обох ширинах.
Окремий запуск: `npm run test:e2e -- tests/e2e/radial-map.spec.ts`.

`npm run test:e2e` збирає застосунок і запускає окремий preview на
`http://127.0.0.1:4174`. Конфігурація містить Chromium для комп’ютера й
мобільний профіль Pixel 7. Сліди та знімки зберігаються для невдалих тестів.

`center-history.spec.ts` перевіряє зміну центру секторами, узгоджені Back/Forward,
«До мене», прямий вхід у кімнату й відсутність повторних кроків. Керований час
перевіряє рух вузлів і ліній, новий перехід під час анімації та точну фінальну
геометрію. Reduced motion перевіряється також при зміні налаштування під час руху.
Три кадри переходу зберігаються для кожного профілю в `test-results/`.
Окремий запуск: `npm run test:e2e -- tests/e2e/center-history.spec.ts`.

Перед першим реальним запуском: `npx playwright install chromium`.
`map-controls.spec.ts` перевіряє масштаб 5–600%, масштабування й вміщення карти,
колесо/drag, покоління та згортання, збереження всіх 74 людей у покажчику,
Back/Forward і кімнату, домашнє скидання, resize 1024 → 320 та зміну камери
під час анімації. На Pixel 7 нативні touch-події через Chromium CDP перевіряють
pan, pinch і прокручування поза картою; цей сценарій пропускається на desktop.
Емуляція не замінює перевірку на фізичному телефоні. Знімки `controls-320.png`
зберігаються в `test-results/` для обох профілів.
Окремий запуск: `npm run test:e2e -- tests/e2e/map-controls.spec.ts`.

Нуль тестів вважається помилкою. Синтетичні набори матеріалів перевіряються
окремо у Vitest через ізольовані тимчасові збірки й не потрапляють у `dist/` проєкту.

`person-search.spec.ts` перевіряє пошук і перехід до всіх 74 людей при одному
видимому поколінні, відновлення камери/глибини/гілок, Back/Forward і «До мене»,
порожній запит, відсутність збігів, оригінальне написання й ширину 320 px.
Окрема синтетична відповідь JSON перевіряє альтернативи, по батькові, тезок,
невідомі/альтернативні роки та клавіатурний вибір із кімнати. Вона існує
лише в перехопленому запиті тесту. Знімки `search-320.png` та
`search-namesakes.png` зберігаються в `test-results/` для обох профілів.
Окремий запуск: `npm run test:e2e -- tests/e2e/person-search.spec.ts`.

`regression.spec.ts` (ROD-028) перевіряє повторні появи → одну кімнату на збереженому вересневому знімку,
фокус після перебудови, текстові альтернативи й цілі 44×44 px для всіх
актуальних центрів на 320 px, довге ім’я з текстом 200%, клавіатуру в
діалозі та відкладені production-запити PlacesMap/PDF. JSON часу готовності
центрів і запитів зберігаються в outputDir і додаються до HTML-звіту.
Перевірки не замінюють фізичний телефон, Safari чи приймання реальних сканів.

[Матриця §14.1, результати й протокол фізичного телефона](../../Docs/Rodovid_Regression_2026-09-28.md).
Повний відтворюваний прогін ROD-028:
`npm run test:e2e -- --workers=2 --output=tmp/rod028-final`.
